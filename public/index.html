Cara pakai di aplikasi HP

  1. Salin salah satu key hb-... di atas.
  2. Di aplikasi AI favoritmu (yang mendukung custom OpenAI endpoint), isi Base URL dengan alamat web ini + /v1, contoh:
    https://bridge-kamu.up.railway.app/v1
  3. Isi API Key dengan key hb-... yang tadi disalin.
  4. Pilih model dari daftar provider yang terikat key tersebut.

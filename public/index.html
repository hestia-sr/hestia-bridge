Kunci API

Satu provider = satu API key. Kuota mengikuti provider masing-masing.

Key saya

Cara pakai

  1. 1

    Buka halaman Provider lewat menu, tempel Base URL + API key provider AI kamu, lalu simpan — koneksi langsung divalidasi.

  2. 2

    Klik + Tambah key di atas — satu API key hb-... langsung dibuat dan terikat ke satu provider.

  3. 3

    Di aplikasi AI di HP yang mendukung custom endpoint OpenAI: isi Base URL dengan
    https://hestia-bridge-production.up.railway.app/v1
    dan API Key dengan key hb-... yang baru dibuat (klik Cara sambung di kartu key untuk salin cepat), lalu pakai seperti biasa lewat prompt.

  4. 4

    Pantau pemakaian tiap key di dashboard ini — jumlah request dan token tercatat otomatis.

Hestia Bridge ·

Provider

Sambungkan AI provider yang kompatibel dengan OpenAI API.

Saat disimpan, Hestia Bridge memanggil GET {baseUrl}/models untuk memvalidasi koneksi.

Daftar provider

Key Saya

Buat API key sendiri, tanpa batasan jumlah.

Worker Saya

Daftarkan worker dari akun AI milikmu — key mode worker milikmu dijawab worker ini secara otomatis.

Cara tes worker

  1. 1

    Pastikan worker kamu online di bagian Worker Saya di atas.

  2. 2

    Klik Buat Key, pilih mode Worker, lalu Buat Key.

  3. 3

    Klik Cara sambung di kartu key, salin Base URL dan API Key ke aplikasi AI di HP, lalu chat seperti biasa.

  4. 4

    Kalau ada jawaban, berarti worker kamu jalan. Kalau tidak dijawab, cek lagi worker-nya online atau tidak.

Cara pakai

  1. 1

    Klik Buat Key — pilih mode Provider (pakai provider yang tersedia) atau Worker (dijawab worker AI).

  2. 2

    Untuk mode Worker: buat dulu worker di bagian Worker Saya, salin tokennya, lalu tempel instruksi yang diberikan ke akun AI milikmu supaya ia bekerja otomatis tiap 5 menit.

  3. 3

    Di aplikasi AI di HP yang mendukung custom endpoint OpenAI: isi Base URL dengan
    https://hestia-bridge-production.up.railway.app/v1
    dan API Key dengan key hb-... milikmu (klik Cara sambung di kartu key untuk salin cepat), lalu pakai seperti biasa lewat prompt.
